# 💸 Bill Splitter

A simple and responsive Bill Splitter web application built using **HTML, CSS, and JavaScript**. It helps calculate how much each person needs to pay when splitting a bill among friends.

## ✨ Features

- Enter the total bill amount
- Enter the number of people
- Calculate the amount payable per person
- Handle invalid inputs
- Simple and responsive user interface
- Instant results with a button click

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 How It Works

1. Enter the total bill amount.
2. Enter the number of people sharing the bill.
3. Click the **Split Bill** button.
4. View the amount each person needs to pay.

### Example

| Total Bill | People | Per Person |
|---:|---:|---:|
| ₹1,000 | 4 | ₹250 |
| ₹1,500 | 3 | ₹500 |
| ₹500 | 1 | ₹500 |
